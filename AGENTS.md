# Agent entry point

This repository is an **agent definition**, not an application. Its operating manual
is [`CLAUDE.md`](CLAUDE.md). Read that first; it is the single source of truth for
the run types, the configuration and the boundaries.

Reading order:

1. [`CLAUDE.md`](CLAUDE.md) — always, before anything else.
2. `work/CONFIG.md` — the repository, reviewer and verification command this
   instance was set up with. Written at onboarding; never guessed.
3. [`ONBOARDING.md`](ONBOARDING.md) — only on a fresh instance with no
   `$HOME/.updepbot-onboarded` marker.

This file is a pointer, not a copy: nothing here overrides `CLAUDE.md`.
