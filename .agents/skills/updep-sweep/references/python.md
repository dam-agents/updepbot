# Python (pip, uv, poetry, pipenv, pip-tools)

Verified 2026-11-19: uv 0.13 in a throwaway project, `uv.lock` moved urllib3
1.26.4 → 1.26.5, `uv sync` and `python -c "import urllib3"` passed.

## Find it

The alert names the manifest — `requirements.txt`, `pyproject.toml`, `setup.py`,
`Pipfile`. Which tool owns it: `uv.lock` → uv, `poetry.lock` → poetry,
`Pipfile.lock` → pipenv, a file whose header says it was generated by
`pip-compile` → pip-tools, otherwise the plain requirements file. The installed
version:

```sh
uv pip list | grep <pkg>          # or: uv pip show <pkg>
poetry show <pkg>
pipenv graph | grep <pkg>
pip show <pkg>
```

## Move it

```sh
uv add "<pkg>==<fixed>"                    # direct dependency, exact
poetry add "<pkg>==<fixed>"
pipenv install "<pkg>==<fixed>"
# pip-tools: change the .in to <pkg>==<fixed>, then pip-compile <input>.in
# plain requirements.txt: change the pin to <pkg>==<fixed>
```

Keep the file's style: `==` stays `==`, `>=` stays `>=`, a `~=` bound is raised to
the lowest bound that admits `fixed`.

For a transitive package, pin the fixed version in the tool's constraint or
override and say so in the pull request. `uv lock --upgrade-package
"<pkg>==<fixed>"` lands exactly `fixed` without adding a constraint; without the
`==`, and for `poetry update` and `pipenv update`, the tool takes the newest
allowed version, not the lowest that clears the advisory; say so when that lands
above `fixed`.

## Regenerate the lockfile

The tool above rewrites its lockfile (`uv.lock`, `poetry.lock`, `Pipfile.lock`,
the compiled requirements). Never run a bare `uv lock`, `poetry update` or
`pipenv update`: it moves everything within the constraints. For pip-tools, run
`pip-compile` on the one input file and check the diff touches one pin.

## Pin style

Exact stays exact; a range stays a range; a lockfile-only repository keeps
`pyproject.toml`/`requirements.in` unchanged and only the lock moves.

## Verify

The tool's frozen install (`uv sync --frozen`, `poetry install`, `pipenv sync`,
`pip install -r <compiled>`), then the repository's `verify` command.

## Toolchain

Python and `uv` ship with the image. Poetry, pipenv and pip-tools are installed
with `mise use -g poetry@<version>` (or `uv tool install poetry`) and
`uv tool install pipenv`; take the version the repository pins
(`poetry.lock`'s `lock-version` on the file, `.python-version`,
`requires-python`).
